# Contributing to Cattledog

Thanks for helping. Cattledog is licensed under the Apache License 2.0.

**Inbound = outbound.** By submitting a contribution, you agree it's licensed under Apache-2.0, the same as the project (see section 5 of `LICENSE`). There's no CLA to sign.

## Guidelines
- Keep pull requests focused, and say what changed and why.
- Run the Rust tests (`cargo test --workspace` in `rust/` and `rust/v2/`) and any demo you touched.
- Never commit secrets, keys, brain files or personal data.
- Be honest about results: say what you tested, on which model and platform.
- Add `SPDX-License-Identifier: Apache-2.0` to new source files.

AI-assisted contributions are welcome. See `AGENTS.md`.
